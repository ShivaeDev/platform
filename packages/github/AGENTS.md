# @shivaedev/github

This package is the shared GitHub REST client for Platform tools and applications. Applications describe the data they need with Schema and decide what to do with it; this package owns authentication, conditional representations, pagination, bounded bodies and GitHub's resource budgets.

Correct observations and typed failures win over quota efficiency, then convenience. Preserve Effect's interruption and caller-owned streaming. Compose platform's outbound HTTP pieces rather than maintaining another HTTP stack. Keep GitHub status translation at one edge, and keep credentials out of failures and telemetry. A rate limit tells a caller when to defer; scheduling and retries belong to that caller.

The loopback GitHub story kit exercises the real service and grows with its public behavior. Usage is in [README.md](./README.md).
