# @shivaedev/agent-pi

This package makes Pi's embedded coding session usable through the shared agent port. Applications keep their storage, scheduling, logs and identity; this package owns provider protocol, event conversion and provider recovery semantics.

Truth about acceptance and completion wins first: a preflight acknowledgement accepts input, a prompt promise is not an acknowledgement clock, and a retrying Pi run is still running. Preserve native session-file references, resume through SessionManager, and keep follow-up distinct from steering. Declare unsupported features before provider work instead of simulating them.

Keep SDK work at the adapter edge with Pi as an optional peer. Prefer Effect scope ownership and typed port failures over another lifecycle abstraction. The story kit drives the real bridge through a scripted SDK peer, using native session files for resume; live provider smokes belong to the adopting application.

Read the [README](README.md) for usage and limits and the repository [AGENTS.md](../../AGENTS.md) for development conventions.
