# @shivaedev/agent-opencode

This package lets Effect applications use OpenCode through the shared agent port without carrying its provider protocol. It owns HTTP and SSE transport, session event projection, delivery and provider recovery. Application storage, wake policy, runner logs and agent identity stay with the application.

Preserve session attribution, acceptance uncertainty and native Effect scope before provider convenience. Queueing waits for idle; steering delivers to active work. Missing evidence never justifies resubmission. Declare only implemented features, and retain unfamiliar provider payloads as raw events.

Keep the MCP SDK at the optional adapter edge. Tool calls belong to the session that made them and end with its scope. The story kit runs the real adapter against a scripted protocol peer; live provider proof belongs to application adoption.

Read the [README](README.md) for usage and the repository [AGENTS.md](../../AGENTS.md) for development conventions.
