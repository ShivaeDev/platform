### Added

- `@shivaedev/jobs`: Run a registered schedule immediately through `runScheduleNow` using its normal queue and handler while preserving its timetable.
- `@shivaedev/admin`: Run schedules from the admin Jobs view on retry-enabled pages, guarded by the existing jobs management permission.
