### Added

- `@shivaedev/quality`: The new `effect/adapter-bridges` rule reports a production file in an `adapters/` folder that uses nothing only an adapter may use: no value of an outside library or Node builtin, no host global such as `window`, `fetch`, timers or `crypto`, no unsafe clock read, no `async`, `throw` or Promise, no `Effect.run*`, no captured context and no export whose declared or inferred type mentions an outside library's type. A type-only import that never reaches an export does not count. Such a file is core code; move it out of `adapters/`. Run `quality baseline write --rule effect/adapter-bridges` to record existing findings while you move them.

### Changed

- `@shivaedev/quality`: Every rule that treats `adapters/` folders differently recognizes them the same way: any directory segment named `adapters`, at any depth.
- `@shivaedev/quality`: Biome's `noDefaultExport` accepts a default export that implements an imported foreign `Plugin` type in any folder, not only in `adapters/`.

- `@shivaedev/skills`: The story-testing skill imports `lessThan`, `atMost`, `greaterThan` and `atLeast` from `@shivaedev/test-story/server/outcomeMatchers.ts`, where they now live.
